# Changelog

Mudanças relevantes para usuários e contribuidores serão registradas aqui a partir desta revisão de documentação. O histórico Git continua sendo a fonte completa para alterações anteriores.

O formato segue a ideia de **Keep a Changelog**, com versões futuras organizadas por impacto público em vez de repetir a lista de commits.

## Unreleased

### Added

- Documentação de status do projeto e critérios de maturidade.
- Guia de suporte para diagnóstico antes de abrir issues.
- Processo de release documentado.
- Template estruturado para propostas de features.

### Changed

- README reorganizado para apresentar estado, build, arquitetura, roadmap e documentação de forma mais direta.
- Guia de contribuição alinhado à direção Ascension e à separação entre preservação e experiência moderna.
- Templates de bug e Pull Request ampliados com contexto de ambiente, risco e evidência de teste.
- Roadmap passou a registrar critérios de saída por marco.
- Política de segurança atualizada para o repositório Ascension e para GitHub Private Vulnerability Reporting.

### Fixed

- Links de suporte, segurança e documentação que ainda apontavam para o repositório de origem.

## Política de versão

Antes de `1.0.0`, mudanças incompatíveis podem ocorrer entre versões menores quando forem necessárias para estabilizar arquitetura, configuração ou formato interno. Ainda assim, mudanças deliberadamente incompatíveis devem ser documentadas aqui e nas release notes.

A partir de `1.0.0`, a intenção é seguir versionamento semântico para interfaces e comportamentos que o projeto declarar estáveis.
