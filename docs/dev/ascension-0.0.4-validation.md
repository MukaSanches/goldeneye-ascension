# Ascension 0.0.4 validation gate

This branch exists only to exercise the release-candidate workflow against `release/ascension-0.0.4` before manual handoff.

Promotion requires the canonical patch stack, deterministic regression contracts, Windows/MSYS2 build, Linux GCC 13/14 builds, executable verification and then the manual Windows playtest documented in `docs/dev/ascension-0.0.4.md`.
