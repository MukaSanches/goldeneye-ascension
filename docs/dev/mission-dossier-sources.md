# Mission Dossier — fontes e escopo

Esta página organiza a campanha de **GoldenEye 007 (Nintendo 64)** em português para navegação rápida no site Ascension.

## Escopo

- 18 fases da campanha principal + Aztec e Egyptian.
- O texto é um guia resumido, não uma reprodução de guias comerciais.
- Os objetivos variam entre Agent, Secret Agent e 00 Agent; o jogador deve conferir o relógio/briefing da dificuldade selecionada.

## Referências consultadas

- GoldenEye Depot — Game Text: https://goldeneyedepot.com/game-text
- GoldenEye Depot — páginas individuais de níveis: https://goldeneyedepot.com/levels/dam
- GoldenEye Depot — exemplo Runway e objetivos por dificuldade: https://goldeneyedepot.com/levels/runway

GoldenEye Depot é um arquivo comunitário não oficial. O conteúdo do site Ascension foi redigido de forma própria e resumida, usando essas fontes para conferência de nomes, ordem e objetivos.
