# Ascension Learning Series

**20 cursos em PDF sobre GoldenEye, história, gameplay e a engenharia do Ascension.**

Esta coleção foi organizada como material educacional independente em PT-BR. Cada curso é um documento fechado, com identidade editorial comum, objetivos, conteúdo, aplicação prática, revisão, glossário e referências.

> O projeto não distribui ROM, assets comerciais extraídos ou outros conteúdos proprietários. GoldenEye, James Bond e marcas relacionadas pertencem aos respectivos titulares.

## Política editorial

Os PDFs são snapshots versionados da documentação educacional. Afirmações sobre o estado do Ascension devem ser confrontadas com [`../PROJECT_STATUS.md`](../PROJECT_STATUS.md), [`../../ROADMAP_ASCENSION.md`](../../ROADMAP_ASCENSION.md) e o código da `main`, que continuam sendo as referências técnicas vivas do projeto.

Correções factuais, melhorias de clareza e atualizações de engenharia são bem-vindas via Pull Request. Mudanças editoriais devem preservar a separação entre fatos históricos, comportamento observado, decisões de produto e trabalho planejado.
